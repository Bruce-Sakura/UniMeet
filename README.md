# UniMeet

A modern, accessible expense sharing and housemate ledger application for university students and housemates.

## Features

- **Household Setup & Management**: Configure housemate rosters and household details.
- **Equal Expense Splitting**: Fair integer-pence division with deterministic remainder distribution.
- **Real-time Net Balances**: Instant calculation of who owes what and who is owed.
- **Expense History**: Full ledger with search, filtering, and deletion support.
- **Local Persistence**: State preserved across page refreshes via browser storage.
- **Accessible & Tested**: Full test coverage and invariant accessibility labels.

## Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Testing**: Vitest + React Testing Library

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Testing

```bash
npm test
```

### Production Build

```bash
npm run build
```
